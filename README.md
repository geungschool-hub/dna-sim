# DNA 복제 모의실험 (dna-sim)

고등학교 진로선택 「생물의 유전」 웹 활동 — 교과서 48쪽 탐구(부록 137쪽 종이 모형)의 인터랙티브 버전.

- 복제 분기점이 **오른쪽 → 왼쪽**으로 풀리는 32염기쌍 무대. [🔓 풀기(8칸)]로 단계적으로 연다
- A/T/G/C 단추로 상보 뉴클레오타이드를 직접 붙인다(틀리면 흔들림 + 「G의 짝은 C」 근거 피드백 + 오답 횟수 기록)
- **DNA 중합효소는 3′ 말단에만** 붙인다는 규칙을 실제로 강제 — 위 가닥은 연속(선도), 아래 가닥은 조각마다 왼쪽→오른쪽(지연)
- 오카자키 조각 4개 → [🔗 DNA 연결효소로 잇기]로 이음새 제거, 그때 선도/지연 이름 공개
- 완성 후 딸 DNA 2개를 「원래 가닥 / 새로 합성된 가닥」으로 표시 → **반보존적 복제**를 눈으로 확인
- 정리하기 4문항(모범답안) — 3번은 학생의 오답 횟수를 끌어와 세포의 교정·수선과 연결
- 💡 더 해보기: **메셀슨·스탈 실험** — 보존적/반보존적/분산적 모델을 고르면 예상 띠를 그려 실제 결과와 대조
- 단일 HTML · 오프라인 동작 · 태블릿/폰 터치 지원 · 진행 자동 저장(localStorage)
